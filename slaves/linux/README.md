# OpenSwarm — Linux Slave Agent (`slaves/linux`)

Turns any Linux SBC (**Arduino UNO Q**, **Arduino Portenta X8**, **Raspberry Pi**, **Nvidia Jetson**) into a Zero-Touch `SwarmNode` Slave speaking the exact same UDP discovery (`4211`) and telemetry/command (`4210`) protocol as the microcontroller slaves.

*(Step 5 in the build roadmap).*
